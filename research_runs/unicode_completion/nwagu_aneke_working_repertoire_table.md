Status: `WORKING_REPERTOIRE_TABLE_NOT_PROPOSAL_REPERTOIRE`

Do not submit this table as a Unicode repertoire.

This table is a source-backed working ledger for Unicode-completion work. It is
not a proposed Unicode repertoire. It records what the current repo can support
from source-layer evidence before representative glyph, usage, and
character-glyph review.

## Proposal-Repertoire Gap

The current working table does not yet answer the Unicode question "what are the
abstract characters?" It identifies the source grid from which that question
must be answered. A proposal-ready repertoire requires cell-level glyph
inspection, usage examples, character/glyph/variant decisions, names, and
properties for each proposed character.
