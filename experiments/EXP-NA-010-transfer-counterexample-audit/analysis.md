# Analysis

The transfer/counterexample audit tests whether the ARTICLE-NA-010
non-promotion invariant is merely a Nwagu-specific rule or a reusable
cultural-heritage computing control.

The audit uses ten compact cases:

- two Nwagu or Nwagu-adjacent count-layer cases;
- two digital-edition and annotation cases;
- one Unicode-process case;
- two rights/authority cases;
- two cultural-heritage ML cases;
- one safe speculative-use case.

Six cases intentionally promote weaker evidence into `source_observed` claims.
The layer gate rejects all six. Four cases preserve their layer and are allowed.
The provenance-only and citation-only baselines remain weak because a provenance
link or citation can coexist with layer promotion.

This is a positive transfer result with a narrow ceiling. It supports a public
methods claim that the invariant can be explained beyond the single Nwagu count
problem. It does not prove completeness, public data release, source review, or
cultural authority.
