# EXP-NA-012 Analysis

This experiment reframes the Article 012 branch from process documentation into
a measurable layer-promotion benchmark.

The benchmark contains twelve claim cases:

- six safe preservation cases that should remain allowed;
- six unsafe promotion cases that should be rejected.

The gate accepted all six safe statements and rejected all six unsafe
promotions. The resulting promotion-error recall is `1.0`, precision is `1.0`,
and derived-layer preservation is `1.0` for this small controlled set.

The result is intentionally bounded. It does not prove that all future agents
will preserve evidence layers. It shows that Article 012 has a substantive
research object: layer-promotion error can be measured as a benchmark task over
source-observed, derived, speculative, and blocked claim cases.
