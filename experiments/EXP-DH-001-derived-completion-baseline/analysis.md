# EXP-DH-001 Analysis

This toy experiment asks whether DH-001 has enough formal substance to remain
alive as a derived hypothesis.

It does not inspect raw manuscripts, does not transcribe new signs, and does not
claim that the Nwagụ Aneke source layer contains 27 rows. The source layer stays
fixed at 26 rows x 8 modifier columns = 208 records.

The task is intentionally narrow: distinguish f-role and v-role labels in a
constructed set of sixteen role-recovery cases. The collapsed source view cannot
distinguish the roles. The derived role-split model can. The shuffled completion
baseline has a 27-row-looking split but assigns the roles wrongly.

The counterexample screen adds six boundary cases. The derived split rejects all
three unsafe source-promotion cases, preserves the safe source/stage/derived
statements, and records zero source-constraint violations. The shuffled
completion still fails the role task and violates two source constraints.

The source-record screen adds eight reviewed source facts from the current chart
transcription and source audit. The derived split preserves all eight without
promoting `27 x 8` into the source layer.

The adversarial screen is the key result of this cycle. Six variants remove the
role-label crutch or present only source-level evidence. The derived model
rejects overclaiming on all six, and the experiment records
`BLOCKED_LABEL_ONLY`: value beyond the f/v labels is not yet demonstrated.

This means the derived split is formally coherent and source-safe enough to keep
under controlled test, but it has not produced a discovery-level result.

The global benchmark gate makes the branch decision explicit. DH-001 passes six
research-quality criteria: reproducible artifact, documented datasets, baseline
comparison, adversarial source safety, transparent metrics, and source-boundary
control. It fails `non_label_generalization`, the criterion that would make the
result globally meaningful. Therefore the correct decision is to park DH-001
before paper-candidate promotion.
