# Research Event Trace

This folder is the control-plane event source for Etisiobi.

The event stream does not replace source files, paper folders, experiment logs, or
the human-readable `decisions/decision_log.jsonl`. It gives the lab one
append-only trace from which current state can be projected.

## Files

- `schema.json` defines the event record shape.
- `research_events.jsonl` is the append-only event stream.
- `current_state.json` is generated by `scripts/project_research_events.py`.
- `current_state.md` is the human-readable projection.
- `artifact_event_index.json` maps artifacts to the events that produced,
  affected, or superseded them.

## Rules

1. Append new events; do not edit historical events except to fix invalid JSON.
2. Every event must say what evidence supports it.
3. User confirmations are allowed as `conversation:<locator>` evidence, but they
   do not substitute for public authority or rights documents.
4. Generated packets and paper drafts are projections, not authoritative state,
   unless an event promotes them.
5. If an artifact is superseded, record it in `supersedes_artifacts` rather than
   deleting it.
