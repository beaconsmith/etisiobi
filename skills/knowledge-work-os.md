# Skill: Knowledge Work Operating System
> Fat skill - pulse, log, inbox, and router workflows for the research lab.

## What This Skill Does

Turns Codex into an operating layer for recurring research and studio knowledge work. Use it for daily paper pulses, research logs, source inboxes, unanswered-message queues, and routing notes across ICegov, PAGC, Oroma feedback, and publication work.

## Thread Model

### Pulse Threads

Run scheduled checks for one domain:
- paper status pulse
- source acquisition pulse
- reviewer-risk pulse
- submission deadline pulse
- Oroma product-feedback pulse
- lab hygiene pulse

Output:
- changed since last pulse
- blocked
- urgent
- needs human approval
- route elsewhere

### Log Threads

Capture daily work without polishing:

```markdown
## YYYY-MM-DD
- Did:
- Learned:
- Sources touched:
- Claims changed:
- Open loops:
- Next:
```

Logs are memory, not evidence. Claims still need source files, citations, and paper control-plane updates.

### Inbox Threads

Collect incoming research work:
- unread or unanswered email/message items
- new PDFs or citations
- reviewer comments
- product feedback
- submission requirements
- task requests

Classify as:
- reply now
- reply today
- source ingestion
- route to paper
- route to product
- FYI/archive
- sensitive/high-review

### Router Threads

Prepare routing packets for the right paper, program, or repo:

```markdown
Target:
Reason:
Context:
Requested action:
Evidence attached:
Deadline:
Approval needed:
```

If no cross-thread messaging tool is available, produce packets for the user or next agent to paste into the target thread.

## Safety

- Do not invent sources, emails, messages, or thread IDs.
- Do not send, delete, archive, publish, or submit without explicit approval.
- Do not let inbox/log summaries replace paper evidence files.
- Promote durable decisions into `decision_log.md`, `claim_map.md`, `reviewer_attack_surface.md`, or the relevant skill only after verification.

## Required Output

Report:
- mode: pulse, log, inbox, or router
- scope and sources inspected
- items found
- approvals needed
- routed packets
- follow-up automation or skill update recommended
