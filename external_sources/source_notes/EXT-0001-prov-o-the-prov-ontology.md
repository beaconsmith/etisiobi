# EXT-0001: PROV-O: The PROV Ontology

URL: https://www.w3.org/TR/prov-o/

Type: standard

Quality: primary

## What It Does

Defines an OWL2 ontology for representing PROV entities, activities, agents, and relations.

## Relationship to BMC

BMC provenance activities and source derivations should align with PROV-O.
