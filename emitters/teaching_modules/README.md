## Release checks

Before releasing a research-derived teaching module, run the relevant claim and publication gates and complete human rights, community-authority and release review. A publicly sourced engagement note must attribute each factual claim, distinguish reported activity from measured outcomes, and contain no private participant data.

The project's commands are documented in [Publication Gate](../../PUBLICATION_GATE.md). Do not present a planned workshop as completed or a workshop attendance count as proof of learning.
