# Read This First

## What new thing did we discover?

Etisiobi found a concrete count-layer drift in the PAGC/Nwagu Aneke research archive:

- The source-observed layer is represented locally as 26 rows x 8 vowel/modifier columns = 208 BMC records.
- The 27 / 216 layer is not source-observed in the current evidence package.
- 27 / 216 appears only as a derived interpretation if the f/v row is split.

The user/lab owner has confirmed this layer model as correct and as the foundation for researching PAGC applications and potentials for designing novel systems.

That matters because several larger PAGC claims depend on treating 27 or 216 as foundational. The current paper blocks those claims from entering the manuscript as unsupported results.

## Why should anyone believe it?

Because the claim is backed by repo-local artifacts and an auditable paper trail:

The claim is deliberately narrow. It does not prove glyph-shape grammar, E6, universal compression, or broad PAGC theory. It proves that the current evidence package must distinguish source-layer counts from derived-layer counts before publication.
