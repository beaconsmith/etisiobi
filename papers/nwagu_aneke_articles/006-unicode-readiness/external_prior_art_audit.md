# External Prior-Art Audit: ARTICLE-NA-006

## Scope

This audit supports the Unicode-readiness article. The article's result is
narrow: a 12-requirement gap matrix shows that the current Nwagu Aneke package
is not Unicode-proposal-ready.

## Compared Literatures

1. Script Encoding Initiative and Unicode proposal practice: proposal work
   requires stable repertoire evidence, character names, representative glyphs,
   usage examples, properties, implementation evidence, and community/source
   review. The current package lacks or blocks several of these.
2. African writing-system documentation: Azuonye, public script-status sources,
   Omniglot, ScriptSource, and Smithsonian metadata identify Nwagu Aneke as a
   real documentation object. They do not supply a proposal-ready repertoire.
3. Digital humanities source criticism: TEI, IIIF, Web Annotation, PROV-O,
   RO-Crate, DataCite, CIDOC CRM, FAIR, and CARE provide infrastructure for
   source and authority-aware documentation. They do not complete source review
   or community authorization.
4. Cultural-heritage governance: CARE and rights-aware heritage practice require
   public release and authority decisions to remain human-controlled.
5. Claim verification and citation-grounded generation: evidence/claim systems
   motivate treating "not ready" as a result rather than smoothing gaps into
   proposal language.

## Novelty Claim Ceiling

The article may claim a reproducible Unicode-readiness gap matrix for the local
Nwagu Aneke evidence package. It may not claim a Unicode proposal, complete
character inventory, public representative glyph set, implementation package, or
community-authorized standards submission.

## Submission-Review Prior-Art Decision

The non-human comparison supports submission-review candidate status if the
paper is framed as a negative readiness audit and evidence checklist. Before
external submission, a human source/domain reviewer should compare the exact
public wording against current Unicode/SEI expectations and African script
documentation practice. That remaining item is a human sign-off gate, not an
unresolved technical-evidence blocker.
