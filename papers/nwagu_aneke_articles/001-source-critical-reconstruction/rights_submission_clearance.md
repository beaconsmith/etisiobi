# Rights and Submission Clearance

Article: `ARTICLE-NA-001`

Status: `MISSING_FOR_EXTERNAL_SUBMISSION`

## Current Scope

The article is currently safe only as a text-only source-critical reconstruction
paper. It can discuss the existence of repo-local evidence objects, but it does
not clear public reproduction of source images, manuscript pages, or an
uncleared glyph dataset.

## What Is Not Yet Cleared

- Public source-image reproduction.
- Public manuscript-page reproduction.
- Public release of a glyph-level corpus.
- Public source-region coordinates.
- Cultural/source authority wording for external publication.
- Final author approval for a named journal submission.

## Minimum Clearance Needed

Before journal submission, the project needs a paper-specific clearance record
that says:

1. Which source files may be named publicly.
2. Which source files may be reproduced publicly.
3. Whether the local chart transcription may be quoted or summarized.
4. Whether the row/vowel ledger can be published as a table.
5. Whether visible logograph leads can be discussed.
6. Who has authority to approve public wording.
7. Whether the selected journal venue is acceptable for this material.

## Current Decision

External submission remains blocked. This file is a clearance checklist, not a
clearance grant.
