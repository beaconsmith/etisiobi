# Rights and Submission Clearance

Article: `ARTICLE-NA-002`

Status: `MISSING_FOR_EXTERNAL_SUBMISSION`

## Current Scope

The article is currently safe only as an internal text-only research draft. It
does not reproduce protected source images, manuscript pages, or uncleared glyph
datasets.

## What Is Not Yet Cleared

- Public source-image reproduction.
- Public manuscript-page reproduction.
- Public release of a glyph dataset.
- Public claim that manuscript holdings have been reviewed.
- Cultural/source authority wording for external publication.
- Final author approval for a named journal submission.

## Minimum Clearance Needed

Before journal submission, the project needs a paper-specific clearance record
that says:

1. Which source materials may be described publicly.
2. Which source materials may be reproduced publicly.
3. Which source materials must remain private or paraphrased.
4. Whether the 26 x 8 source-layer statement may be used in a public article.
5. Whether the derived f/v split may be discussed as a design/analysis layer.
6. Who has authority to approve this public wording.
7. Whether the selected journal venue is acceptable for this material.

## Current Decision

External submission remains blocked. This file is a clearance checklist, not a
clearance grant.
