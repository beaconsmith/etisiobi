# Rights and Submission Clearance

Article: `ARTICLE-NA-010`

Status: `MISSING_FOR_EXTERNAL_SUBMISSION`

## Current Scope

The article is currently safe only as a text-only systems paper over evidence
labels and claim transformations. It does not reproduce protected source images,
manuscript pages, or uncleared glyph datasets.

## What Is Not Yet Cleared

- Public source-image reproduction.
- Public manuscript-page reproduction.
- Public release of a glyph or claim dataset beyond the repo-local synthetic
  cases.
- Cultural/source authority wording for external publication.
- Final author approval for a named journal submission.

## Minimum Clearance Needed

Before journal submission, the project needs a paper-specific clearance record
that says:

1. Which source claims may be used as examples.
2. Which blocked claims must remain private or generalized.
3. Whether the Nwagu Aneke source-layer model may be discussed publicly.
4. Whether the synthetic layer-safety cases can be released.
5. Who has authority to approve the public wording.
6. Whether the selected journal venue is acceptable for this material.

## Current Decision

External submission remains blocked. This file is a clearance checklist, not a
clearance grant.
