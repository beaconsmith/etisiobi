# Nwagu Aneke Article Program

Status: spawned as a goal program on 2026-06-19.

Purpose: produce ten serious research article candidates derived from the
Nwagu Aneke artifact, with each candidate grounded in source reconstruction,
artifact structure, digitization, rights/authority, or a falsifiable application
of the source/derived layer model.

This program is not allowed to promote PAGC grand-theory claims as article
results. The working foundation remains:

```text
source-observed layer: 26 rows x 8 vowel/modifier columns = 208 records
derived layer: 27 / 216 only if the f/v row is split
```

## Files

- `GOAL-NA-ARTICLES-001-create-10-novel-articles.md` is the goal file.
- `prior_art_scan.md` records the local and external research done before goal
  creation.
- `article_candidates.md` defines the ten article candidates.
- `article_scores.json` contains initial scores and activation status.

## Activation Rule

Only three article candidates may be active at once. An article candidate can
be activated only after:

1. source evidence is identified;
2. novelty is stated as a hypothesis, not a claim;
3. the first experiment or audit is specified;
4. authority/rights blockers are explicit;
5. a falsification condition exists.
