# Methods Map

> Paper: `community-os-pilot`

## Current Method

Design Science Research. ADR only applies if there is real organizational intervention.

## Evaluation Maturity Levels

| Level | Meaning | Current status |
|---|---|---|
| Design validity | Artifact requirements and design logic are coherent | possible |
| Feasibility | Prototype or technical path works | audit needed |
| Utility | Users/tasks show usefulness | not established |
| Impact | Organizational/community outcomes | not established |

## Rule

The paper may only claim the highest evidence level actually supported by audited artifacts.
