# PAGC Reset: False Until Proven

Date: 2026-04-25

## Rule

All PAGC claims are false until the repository contains source evidence, an extraction method, and a falsification test.

This applies to:

- `27x8` as a source-derived structure,
- E6 / exceptional Lie correspondence,
- universal compression,
- genetic-code isomorphism,
- 216-token sovereign memory advantage,
- any claim that the Nwagụ Aneke script directly encodes a formal generative theory.

## What Survives The Reset

PAGC remains valuable as a research program if it produces:

- a defensible archive of Nwagụ Aneke source material,
- a reproducible transcription and inventory process,
- falsifiable experiments on Igbo tokenization and compression,
- a disciplined way to separate analogy from evidence,
- tooling that turns research into developer-facing product feedback.

## Research Method From Deep Learning / Physics

| Section | PAGC equivalent | Current allowed work |
|---|---|---|
| 2.1 Solvable settings | tiny claims that can fail | source inventory count, chart transcription, BPE k sweep |
| 2.2 Simplifying limits | strip away grand theory | start with Omniglot + Azuonye only; ignore E6 and universality |
| 2.3 Simple empirical laws | repeatable curves | compression/perplexity vs vocabulary size, cache size, corpus size |
| 2.4 System parameters | knobs and regimes | base count, modifier count, dialect mix, tokenizer, tone handling |
| 2.5 Universal phenomena | cross-domain recurrence | only after independent corpora and baselines survive |

## Hard Gate

No paper, product narrative, or README may state PAGC as established theory. Use:

- "hypothesis under test"
- "proposed framework"
- "source-integrity pending"
- "speculative analogy"

Do not use:

- "proves"
- "universal"
- "Principia-level" without a linked falsification result
- "27x8 structure" without saying whether it is observed, extracted, or hypothesized

## Derived Hypothesis Lane

The reset blocks false source claims; it does not block modern formalization.
Derived hypotheses are allowed when they are clearly labeled as derived research
constructions, define their rules, face baselines or counterexamples, and never
claim to be historical facts.

Use [`DERIVED_HYPOTHESIS_CHARTER.md`](DERIVED_HYPOTHESIS_CHARTER.md) when a
branch asks what formal structure can be built from the Nwagụ Aneke evidence
rather than what the source historically proves.
