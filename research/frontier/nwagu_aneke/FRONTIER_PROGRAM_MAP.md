# Nwagu Aneke Frontier Program Map

## Operating Frame

This map aligns the Nwagu Aneke program with the open frontier ecosystem goal.
The program is not constrained to one benchmark, paper, discipline, application,
or theory. Exploration is broad; promoted claims remain evidence-gated.

Current invariant:

```text
source-observed: 26 rows x 8 vowel/modifier columns = 208 records
derived: 27/216 only by f/v split
```

No branch may promote 27/216 as source-observed unless new source evidence
supports it.

## First Parallel Exploration Sprint

Track A, source and reconstruction:

- Create `EXP-NA-002-source-note-azuonye-1992.md`.
- Expected learning: whether the count-layer audit is confirmed, revised, or
  weakened by the controlling source.

Track B, computation and representation:

- Create a bounded representation experiment plan comparing source-observed,
  derived, and speculative layer labels in one machine-readable schema.
- Expected learning: whether the claim-layer schema can drive validation and
  benchmark fixtures.

Track C, interface, preservation, or application:

- Prototype a static layered-claim view or atlas outline that shows observation,
  derivation, speculation, and application as separate visual layers.
- Expected learning: whether non-specialists can understand the distinction
  without reading the whole research apparatus.

The sprint increases informed possibilities. It does not force an early winner.
