## Outreach Constraints

- Do not send bulk requests.
- Do not request private family data, manuscripts, or culturally restricted
  material without a rights/authority protocol.
- Ask first for bibliographic clarification, deposit completeness, holding
  existence, and permission pathways.
- Treat every response as a source record requiring date, correspondent role,
  storage path, rights status, and claim-layer effect.

## Source Request Template Requirements

Any future request should include:

1. the exact citation and local file hash/page observation;
2. the narrow question: whether Appendix II exists in a recoverable file or
   archival holding;
3. a statement that no public reproduction is being requested;
4. a request for the correct rights/permission route if material exists;
5. a request for preferred citation if a source is provided.
